# 씨마스 모션그래픽 프롬프트

씨마스에듀 사내연수에서 교과서의 핵심 개념을 짧은 모션그래픽으로 설명하는 실습 자료입니다. 12개 교과의 완성 프롬프트 142편을 한 파일에 담았습니다. 단원별 예시를 골라 그대로 복사하거나, 교과별 기본 틀에 수업 내용을 넣어 새 프롬프트를 작성할 수 있습니다.

## 실습 방법

1. [씨마스 모션그래픽 프롬프트 HTML](./씨마스_모션그래픽_프롬프트.html)을 선택하고 GitHub 파일 화면의 **Download raw file** 버튼으로 내려받습니다.
2. 내려받은 파일을 웹 브라우저에서 열고 상단 탭에서 교과를 선택합니다.
3. **단원별 완성 프롬프트 예시**에서 수업에 맞는 주제를 고릅니다. 예를 들어 **경제수학 → 직구 가격의 비밀**은 환율을 20초 영상으로 설명하는 예시입니다.
4. 프롬프트 상자를 클릭한 뒤 실습에 사용하는 AI 도구의 대화창에 붙여넣습니다. 다른 주제로 만들려면 **기본 틀**을 복사하고 대괄호 `[ ]` 안을 수업 내용으로 바꿉니다.
